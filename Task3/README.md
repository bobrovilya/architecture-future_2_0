# Технический радар (категории: Adopt / Trial / Assess / Hold)

### Adopt	
Проверенные решения для новой архитектуры: Snowflake, Kafka, React, Golang

### Trial
Пилотные проекты для оптимизации производительности: Apache Arrow (для Data Lake), gRPC (для внутренних API)

### Assess
Оценка для будущего масштабирования: Flink (для потоковой аналитики), Kubernetes (для оркестрации)

### Hold
Устаревшие технологии, запланирован отказ: SQL Server 2008, Power Builder, Apache Camel

# Ключевые этапы и их обоснование

### 1. Декомпозиция доменов (июль–октябрь 2025)

- На этом этапе закладывается фундамент будущей архитектуры.
- Начинается переход от монолита к микросервисам.

### 2. Работа с DWH (август–ноябрь 2025)

- Миграция на Snowflake.
- Замена устаревшего SQL Server для ускорения аналитики.

### 3. Интеграция (август–ноябрь 2025)

- Kafka приходит на смену Camel
- Асинхронные события вместо прямых запросов к DWH.
- Внедрение каталога метаданных для отслеживания источников и качества данных.
