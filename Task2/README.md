# Домены и их ответственность

Система разделена на 4 основных домена, каждый со своей зоной ответственности и независимым хранилищем данных:

### 1. Медицинский домен.
Обработка медицинских данных (снимки, диагнозы, истории болезней)Хранение мед. карт, результатов исследований. 

### 2. Финансовый домен.
Управление платежами, кредитами, страховками. Хранение финансовых документов, транзакций, договоров.

### 3. Операционный домен.
Управление клиниками, персоналом, инвентарем. Расписания, заказы, логистика.

### 4. Аналитический домен.
Агрегация данных для отчётности и BI. Тут происходит вся магия с хранением больших данных и формирование аналитики.

# Аргументы и факты

### 1. DDD
- Каждый домен отвечает только за свою предметную область.
- Данные не дублируются в разных доменах.
- Медикам не зачем знать о финансовых транзакциях, поэтому данные изолированы границами домена.

### 2. Меньше связанности и зависимостей
DWH больше не единой точка правды, тк данные синхронизируются через шину событий.

### 3. Разделение данных
Мед. данные (большие и чувствительные) изолированы в Data Lake, финансовые данные хранятся в ACID-совместимой СУБД.

### 4. Масштабируемость
При необходимости домен можно масштабировать

### 5. Интеграция
Благодаря наличию шины данных (Kafka) можно в будущем интегрироваться с любой системой.
